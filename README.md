# Dotfiles

Generated by: GPT-6 (Codex)

保留现有 Zsh、Vim、tmux 配置；默认启用 fzf、fdfind、ripgrep、zoxide、
Zsh 自动建议和语法高亮。tmux 使用原生配置。已有 p10k 可继续使用，安装器不下载它。

## 安装

```sh
git clone <your-repo-url> ~/.dotfiles
cd ~/.dotfiles
./install.sh --check
./install.sh --apply
exec zsh
```

`--check` 只检查命令，不写文件、不下载、不执行 sudo。Ubuntu 24.04 的包清单在
[deps/ubuntu-packages.txt](deps/ubuntu-packages.txt)，缺少时可以手动安装：

```sh
sudo apt install bash ca-certificates curl git zsh vim tmux fd-find ripgrep zoxide coreutils tar util-linux
```

`--apply` 创建基础目录，依次执行 `config/zsh/install.sh`、`config/vim/install.sh`、
`config/tmux/install.sh`，最后执行验证。可重复运行；正确链接保持不动，冲突文件先备份。
已有 tmux 会话不会被重启；要立即更新它，可执行 `tmux source-file ~/.tmux.conf`。

缺失的插件按 [deps/git-components.tsv](deps/git-components.tsv) 的 Git 提交 clone。
现有插件版本不同或有已跟踪文件修改时停止，不自动覆盖。
Vundle 保留全部现有插件声明；fzf 使用对应仓库的 `install --bin` 安装，
Zsh 和 Vim 共用 `~/.local/bin/fzf`。新机器第一次安装需要能访问 GitHub 及其 release 下载。

## 从哪里修改

| 内容 | 文件 |
| --- | --- |
| 通用别名 | `config/zsh/aliases.zsh` |
| 历史、PATH、编辑器 | `config/zsh/core.zsh` |
| 补全 / 按键 / 提示符 | `config/zsh/completion.zsh`、`keybindings.zsh`、`prompt.zsh` |
| 当前机器的路径、代理、工具开关 | `~/.zshrc.local`，不进入 Git |
| 个人别名、最后覆盖的设置 | `~/.zshrc.local.after`，不进入 Git |
| Vim 基础设置、映射、插件 | `config/vim/.vim/config/` |
| 只用于本机的 Vim 设置 | `~/.vimrc.local`，不进入 Git |
| tmux | `config/tmux/.tmux.conf` |

新机器默认不启用开发工具模块。需要时复制示例后编辑：

```sh
cp ~/.dotfiles/config/zsh/.zshrc.local.example ~/.zshrc.local  # 已有则直接编辑，别覆盖
vim ~/.zshrc.local
```

例如 `DOTFILES_TOOLS=(node qemu uv rust cross wsl)`；对应参数见示例。
这些模块只设置环境，不安装 Node、QEMU 或工具链。zoxide 默认启用，不需要写进这个数组。
`j 目录` 智能跳转，`ji` 交互选择；Ctrl-R 搜历史，Ctrl-T 找文件，Alt-C 找目录。
Vim 使用 `<Space>ff` 找文件、`<Space>fg` 输入内容搜索、`<Space>fb` 切换 buffer。

个人配置文件仍会影响新启动的 Zsh，只是无需修改通用配置。
如果想试验且完全不影响本机入口，使用 [验证文档](docs/verification.md) 的临时目录方法。

## 验证与回滚

```sh
./scripts/verify.sh
./scripts/test.sh
./scripts/rollback.sh --list
./scripts/rollback.sh <BACKUP_ID>
```

备份位于 `~/.local/state/dotfiles/backups/`，每次安装输出对应 ID。
回滚恢复该次安装前的文件、目录和链接；如发现目标已被你修改，会先停止。
插件、历史、缓存、本机设置保留。回滚不撤销直接修改的仓库源码；源码用 Git 管理，
本次接管前的完整快照见 [迁移记录](docs/migration.md)。

`~/.vim` 保持链接到 `config/vim/.vim` 的现有结构。插件下载目录 `bundle/` 被 Git 忽略；
持久撤销放在 `~/.local/state/vim/undo/`。完整 Git 克隆不包含下载的插件，需要运行安装器补齐。
移动此仓库后，应从新位置再次执行 `./install.sh --apply` 修复绝对链接。

## Git

本目录与旧 `~/zsh-config` 独立。旧仓库保留；Git 初始化、首次提交和远端连接由你处理。
首次提交前执行 `git status --short` 和 `git status --short --ignored`，确认个人设置、插件下载
和运行数据没有进入 Git。手动更新插件后，应检查并同步依赖清单的提交号，再在新环境验证。
